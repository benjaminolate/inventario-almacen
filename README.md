# Inventario Almacén (demo)

Demo para celular de un sistema de inventario para un almacén chico.

- Catálogo precargado con productos típicos de almacén.
- Vender, recibir mercadería, contar por sector e historial.
- El stock se calcula como: último conteo + compras − ventas desde ese conteo, así cada sector se puede contar en un día distinto.
- Escaneo de códigos de barras con la cámara del celular.

Los datos de la demo se guardan solo en el navegador de quien la usa. "Reiniciar demo" vuelve a los datos de ejemplo.
